## 🔧 核心功能

### 1. 网络状态监测

```typescript
const { isConnected } = useNetwork();
// 实时监测 WiFi/移动数据连接状态
// 网络变化时自动触发重新同步
```

### 2. 数据缓存

```typescript
// 保存数据 (自动添加时间戳)
await cache.set('devices', devicesData);

// 获取数据 (自动检查过期)
const devices = await cache.get('devices');
// 返回 null 如果不存在或已过期 (>5 分钟)
```

### 3. 自动同步

```typescript
// 网络恢复时自动调用
useEffect(() => {
  if (isConnected) {
    triggerSync(); // 全量同步所有数据
  }
}, [isConnected]);
```

### 4. 状态指示器

- ✅ 在线且同步完成 → 不显示
- 🔄 同步中 → 蓝色背景 + 加载动画
- ❌ 离线 → 橙色背景 + 提示文字
- ⚠️ 同步失败 → 红色背景 + 错误信息

## 📱 用户体验

### 在线模式
1. 从 API 获取最新数据
2. 自动缓存到本地
3. 支持下拉刷新

### 离线模式
1. 显示离线状态提示
2. 从缓存加载数据
3. 禁用下拉刷新
4. 缓存过期后显示空状态

### 网络恢复
1. 自动检测网络恢复
2. 后台自动同步数据
3. 静默更新 UI
4. 显示同步成功提示
