# 📚 天链V3 - 知识库系统

> 充电桩智能运维知识库，包含故障诊断、维修手册、专家经验和智能推荐。

## 🎯 系统目标

### 核心价值
- **快速故障诊断**: 减少故障排查时间
- **标准化维修流程**: 确保维修质量一致性  
- **知识积累与传承**: 避免经验流失
- **智能推荐**: 基于相似故障推荐解决方案

### 关键指标
| 指标 | 目标值 | 当前值 |
|------|--------|--------|
| 平均故障诊断时间 | < 5分钟 | - |
| 维修方案准确率 | > 95% | - |
| 知识库覆盖率 | > 90% | - |
| 用户满意度 | > 4.5/5 | - |

## 🏗️ 系统架构

```mermaid
flowchart TD
    subgraph inputLayer [输入层]
        faultReport[故障报告<br/>设备ID + 症状描述]
        manualSearch[手动搜索<br/>关键词/分类]
        autoDetection[自动检测<br/>设备数据异常]
    end
    
    subgraph processingLayer [处理层]
        nlpEngine[NLP引擎<br/>症状解析]
        similaritySearch[相似度搜索<br/>向量检索]
        ruleEngine[规则引擎<br/>诊断逻辑]
    end
    
    subgraph knowledgeBase [知识库]
        faultDB[故障数据库<br/>历史案例]
        solutionDB[解决方案库<br/>维修步骤]
        manualDB[手册库<br/>技术文档]
        expertDB[专家经验库<br/>最佳实践]
    end
    
    subgraph outputLayer [输出层]
        diagnosisResult[诊断结果<br/>可能故障列表]
        solutionSteps[解决方案<br/>详细步骤]
        relatedCases[相关案例<br/>历史参考]
        preventionTips[预防建议<br/>避免复发]
    end
    
    %% 连接关系
    inputLayer --> processingLayer
    processingLayer --> knowledgeBase
    knowledgeBase --> outputLayer
    
    %% 反馈循环
    outputLayer -->|用户反馈| knowledgeBase
```

## 📋 知识库内容结构

### 1. 故障分类体系

#### 一级分类 (按设备模块)
```dataview
TABLE 故障数量, 平均解决时间, 常见症状
FROM "故障分类"
WHERE 一级分类 = "电气系统"
SORT 故障数量 DESC
```

**主要分类**:
- **电气系统** (电压/电流异常、漏电保护、充电故障)
- **通信系统** (网络连接、数据传输、协议错误)
- **机械系统** (锁止机构、充电枪、显示屏)
- **热管理系统** (温度异常、散热故障)
- **软件系统** (固件错误、配置问题、数据异常)

#### 二级分类 (按故障类型)
```yaml
电气系统:
  - 充电故障:
    - 无法启动充电
    - 充电中断
    - 充电速度异常
  - 电压异常:
    - 过压保护
    - 欠压保护  
    - 电压波动
  - 电流异常:
    - 过流保护
    - 电流不平衡
    - 漏电流
```

## 📊 数据统计与分析

### 故障统计看板
```dataviewjs
// 故障统计图表
const data = await dv.query(`
    SELECT 
        故障分类,
        COUNT(*) as 数量,
        AVG(解决时间) as 平均时间,
        AVG(满意度) as 满意度
    FROM "故障记录"
    WHERE date >= date(today) - dur(30 days)
    GROUP BY 故障分类
    ORDER BY 数量 DESC
`);

// 生成图表
dv.paragraph("### 📈 故障统计 (最近30天)");
dv.table(["分类", "数量", "平均时间", "满意度"], data.values);
```

### 知识库质量指标
| 指标 | 计算公式 | 目标值 |
|------|----------|--------|
| **知识覆盖率** | 有解决方案的故障数 / 总故障数 | > 90% |
| **解决方案准确率** | 有效解决方案数 / 总方案数 | > 95% |
| **平均诊断时间** | 总诊断时间 / 诊断次数 | < 5分钟 |
| **用户满意度** | 满意评价数 / 总评价数 | > 4.5/5 |
