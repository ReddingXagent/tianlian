## 二、协议详细分析

### 2.1 储能逆变器 Modbus 协议（EAHI5-20K-TH-G3 V1.5）

#### 2.1.1 通信参数
| 参数 | 值 |
|------|-----|
| 物理接口 | RS485（A/B/GND） |
| 波特率 | 默认9600bps（可选1200/2400/4800/9600） |
| 数据格式 | 8位数据位 + 奇/偶校验/无校验 + 1停止位 |
| 模式 | RTU模式 |
| 从机地址 | 1~247 |
| CRC校验 | CRC-16（低字节在前） |

#### 2.1.2 功能码
| 功能码 | 名称 | 用途 |
|--------|------|------|
| 0x02 | 读离散量输入 | 读取告警/故障状态（bit级） |
| 0x03 | 读保持寄存器 | 读取控制参数/设置量 |
| 0x04 | 读输入寄存器 | 读取遥测数据（电压/电流/功率/温度等） |
| 0x06 | 写单个保持寄存器 | 控制命令（开关机/功率设定等） |
| 0x10 | 写多个保持寄存器 | 批量参数设置 |

#### 2.1.3 寄存器分类与地址映射

**A. 设备信息寄存器（地址0-13）**
- 外观版本、MCU软件版本、MCU硬件版本
- USB状态（升级状态：导出/导入/升级中/成功/失败）
- 升级进度（百分比）
- 串口升级状态

**B. 运行状态寄存器（地址14-110）**
- 自检项目、自检状态
- 电表/BMS/DSP正常标志
- 电池能量、SOC、运行时间
- 发电量/用电量/并网量/购电量/充电量/放电量（当日/累积）
- 自给自足比例、购买电量比例、上网电量比例

**C. 电网监控寄存器（地址100-1135）**
- A/B/C相电网频率、电压、电流
- A/B/C相有功功率、无功功率、视在功率
- 功率因数
- 外部CT电流/功率
- 漏电流、零地电压

**D. 逆变输出寄存器（地址1141-1236）**
- A/B/C相逆变电压、电流、频率
- 逆变有功/无功/视在功率
- 负载电压/电流/功率
- 发电机状态（电压/电流/频率/功率）

**E. 电池系统寄存器（地址1071-1074、4096-4649）**
- 电池电压、电流、功率、SOC
- BMS下发充电/放电电流
- EAST-BCU在线数量、告警字（3个）
- EAST-BMS数据（电池总电压、充放电状态、SOC/SOH、温度）
- 模组级Cell电压（5120+地址，每模组24个Cell）
- 模组级Cell温度（5144+地址）
- 告警事件/保护事件（整组过压/欠压、过流、温度异常等）

**F. 光伏输入寄存器（地址1057-1065）**
- PV1/PV2电压、电流、输入功率
- ISO检测电阻（Rx/Ry）
- 母线电压（BUS+/BUS-）

**G. 控制寄存器（地址1024-1035）**
- 开关机指令
- 逆变有功设定
- PV有功设定
- 功率因数设定
- 无功设定
- 电压设定
- 充放电电压/功率设置
- 系统运行模式（电池优先/家庭负载优先/电网优先/全功率馈网/应急后备/纯PV/强制离网）

**H. 温度寄存器（地址1285-1287）**
- PV温度、逆变温度、机内温度

**I. 三相电表数据（地址2048-2203）**
- 4路组合有功总电能
- 4路当前正向/反向有功总电能
- 4路A/B/C相电压、电流
- 4路有功总功率、无功总功率
- 4路功率因数、频率

**J. BCU/BCU状态寄存器（地址4096-4145）**
- BCU在线/最大数量
- BCU告警字1-3（BMU通信异常、接触器故障、母线异常、BMS故障等）
- BCU软件/硬件版本
- 上电阶段、系统工作状态
- 电池SOC、机柜在线标志
- 采样温度/母线电压/DC电压/电池电流
- 高压下电原因、主接触器状态、逆变器连接状态

#### 2.1.4 故障码体系（离散量输入 0x02）

**电网侧故障（地址0-47）**
- 三段过压/欠压（A/B/C相）
- 三段过频/欠频（A/B/C相）
- 零地电压告警、孤岛故障、锁相失败

**逆变侧故障（地址48-111）**
- 快速过流（A/B/C相）
- 有效值过压/欠压（A/B/C相）
- 有效值过流（A/B/C相）
- 硬件过流关机、逐波限流
- 直流分量过流
- PV快速过流/过压/过流/无PV

**电池侧故障（地址112-143）**
- BuckBoost快速过流、飞跨电容过压
- 电池未连接、EOD、SOC低
- BMS通信异常、电池组故障
- 电池电压过压、接反故障

**母线侧故障（地址144-159）**
- BUS+/BUS-快速过压/欠压
- 母线硬件过压、短路、不平衡

**温度故障（地址160-162）**
- 机内温度、PV温度、逆变温度过温

**继电器/接触器故障（地址163-171）**
- 电网/逆变/发电机继电器故障（A/B/C相）

**过载故障（地址172-195）**
- 逆变/旁路110%/125%/150%/200%过载（A/B/C相）

**其他故障（地址196-223）**
- 绝缘对地阻抗故障、漏电流超标
- 电表反接、监控SCI通信异常
- 风扇故障、软硬件版本不匹配
- SPI FLASH故障、并机ID重复

**BCU/BMS故障（地址512-671）**
- BMU1-8通信异常
- 主接触器闭合/粘连故障
- 母线过压/欠压、DC过压/欠压
- 电池过流、预充超时
- BMS1-8故障/告警
- 整组过压/欠压、充电/放电过流
- 充电/放电高温/低温
- 温度/电芯不均衡
- SOC过低、绝缘等级低
- 单体过压/欠压

### 2.2 充电桩 MQTT 协议（V2.2.0）

#### 2.2.1 通信架构
| 参数 | 值 |
|------|-----|
| 协议 | MQTT 3.1.1 |
| 传输层 | TCP长连接 |
| 主题格式 | `mqtt.{方向}.{类型}.{设备地址}TCU地址` |

#### 2.2.2 MQTT主题
| 主题 | 方向 | 功能 |
|------|------|------|
| `mqtt.dev.login.{设备}TCU` | 设备→平台 | 充电桩注册上线 |
| `mqtt.platform.login.{设备}TCU` | 平台→设备 | 注册响应 |
| `mqtt.dev.monitor.{设备}TCU` | 设备→平台 | 监控数据上报 |
| `mqtt.platform.monitor.{设备}TCU` | 平台→设备 | 监控响应 |
| `mqtt.dev.control.{设备}TCU` | 设备→平台 | 控制响应 |
| `mqtt.platform.control.{设备}TCU` | 平台→设备 | 控制指令 |
| `mqtt.dev.business.{设备}TCU` | 设备→平台 | 业务数据 |
| `mqtt.platform.business.{设备}TCU` | 平台→设备 | 业务响应 |

#### 2.2.3 消息类型编码

**注册上线类型（0x1000-1FFF）**
- 设备注册、心跳、版本查询

**监控类型（0x2000-0x3FFF）**
- 状态数据上报、故障信息上报（0x122006/0x112006）
- 电能数据上报、BMS数据上报

**设置类型（0x4000-0x5FFF）**
- 参数设置、控制命令（启停/功率限制）

**业务类型（0x6000-0x7FFF）**
- 充电业务、计费、刷卡

#### 2.2.4 故障编码体系

**故障等级**
| 等级 | 编码 | 说明 |
|------|------|------|
| 紧急故障 | 0x01 | 需立即停机处理 |
| 一般故障 | 0x02 | 可延迟处理 |
| 严重告警 | 0x03 | 需关注但不停机 |
| 一般告警 | 0x04 | 提示信息 |

**故障编码规则**：类型码 + 编码唯一值（如0x0101=功率控制单元急停故障）

**主要故障分类**：

| 分类 | 故障示例 | 编码范围 |
|------|---------|---------|
| 功率控制单元 | 急停/烟雾/水浸/防雷器/断路器/风扇故障 | 0x0101-0x01FF |
| 充电模块 | PFC故障/交流输入故障/直流输出短路/过流/过压 | 0x0201-0x02FF |
| 充电控制器 | 过温/接口过温/电子锁故障/绝缘检测故障 | 0x0301-0x03FF |
| 交流配电 | 接触器粘连/拒动/继电器故障/过压/欠压 | 0x0401-0x04FF |
| 直流配电 | 接触器故障/熔断器故障/泄放回路故障 | 0x0501-0x05FF |
| BMS相关 | 通信异常/电池反接/主接触器故障 | 0x0601-0x06FF |
| 环境安全 | 门禁/烟感/避雷器/接地/水浸 | 0x0701-0x07FF |
| 通信模块 | CAN通信/电能表通信/控制单元通信 | 0x0801-0x08FF |

### 3.2 数据采集策略

#### 3.2.1 Modbus 设备（逆变器/PCS/EMS）

| 数据类型 | 采集频率 | 寄存器范围 | 说明 |
|---------|---------|-----------|------|
| 遥测数据 | 1秒 | 0x0000-0x0400 | 电压/电流/功率/温度 |
| 状态数据 | 2秒 | 0x0400-0x0800 | SOC/运行状态/告警标志 |
| 故障数据 | 事件触发 | 离散量0x02 | 故障码实时上报 |
| 电表数据 | 5秒 | 0x0800-0x0900 | 4路电能/功率/因数 |
| BMS数据 | 2秒 | 0x1000-0x1400 | 电池簇数据 |
| Cell数据 | 10秒 | 0x1400+ | 模组级电压/温度 |

**采集优化**：
- 批量读取：单次请求最多读取125个寄存器（避免超时）
- 帧间隔：9600bps下，帧间隔≥4.01ms（3.5字符时间）
- 超时设置：请求超时3秒，重试2次

#### 3.2.2 充电桩（MQTT）

| 数据类型 | 上报频率 | 消息类型 | 说明 |
|---------|---------|---------|------|
| 状态数据 | 30秒 | 0x2000系列 | 充电状态/功率/SOC |
| 故障数据 | 事件触发 | 0x122006/0x112006 | 故障码+时间+源 |
| 电能数据 | 5分钟 | 0x2000系列 | 充电电量/功率 |
| BMS数据 | 5秒 | 0x2000系列 | 电池参数 |
| 心跳 | 60秒 | 0x1000系列 | 设备在线状态 |

## 四、故障诊断方案

### 4.1 故障分级响应

| 级别 | 响应时间 | 处理方式 | 示例 |
|------|---------|---------|------|
| P0-紧急 | 5分钟 | 自动停机+告警+派单 | 母线短路/电池接反/烟雾报警 |
| P1-严重 | 30分钟 | 降额运行+告警+派单 | BMS通信异常/接触器粘连 |
| P2-一般 | 2小时 | 记录+计划维护 | 风扇故障/门禁异常 |
| P3-提示 | 24小时 | 记录+观察 | 温度偏高/通信丢包 |

### 4.2 故障诊断树

#### 4.2.1 储能逆变器故障诊断

```
逆变器故障
├── 电网侧故障
│   ├── 过压/欠压 → 检查电网质量/调整保护阈值
│   ├── 过频/欠频 → 检查电网频率/孤岛保护
│   └── 继电器故障 → 检查继电器线圈/控制电路
├── 逆变侧故障
│   ├── 过流 → 检查负载/短路/IGBT
│   ├── 过温 → 检查风扇/散热片/环境温度
│   └── 直流分量 → 检查电容/控制算法
├── 电池侧故障
│   ├── BMS通信异常 → 检查CAN/RS485线路/BMS电源
│   ├── SOC异常 → 校准BMS/检查采样电路
│   └── 接触器故障 → 检查线圈/触点/驱动电路
├── 光伏侧故障
│   ├── PV过压 → 检查光伏阵列/MPPT
│   ├── ISO故障 → 检查绝缘/接地
│   └── 无输入 → 检查接线/断路器
└── 通信故障
    ├── Modbus超时 → 检查RS485/地址/波特率
    └── 数据异常 → 检查CRC/线路干扰
```

#### 4.2.2 充电桩故障诊断

```
充电桩故障
├── 充电模块故障
│   ├── 交流输入故障 → 检查断路器/接触器/电网
│   ├── 直流输出故障 → 检查接触器/熔断器/电缆
│   └── PFC故障 → 检查功率器件/驱动电路
├── 控制单元故障
│   ├── CAN通信 → 检查终端电阻/线路/BMS
│   ├── 电子锁 → 检查锁体/驱动电路
│   └── 导引故障 → 检查控制导引电路
├── 安全保护故障
│   ├── 绝缘故障 → 检查绝缘/接地/潮湿
│   ├── 过温 → 检查风扇/通风/环境温度
│   └── 防雷器 → 检查防雷模块/接地
└── 业务故障
    ├── 刷卡机 → 检查读卡器/通信
    ├── 电能表 → 检查RS485/电表电源
    └── 计费 → 检查ESAM/时钟
```

### 4.3 故障码快速查询表

#### 4.3.1 储能逆变器关键故障码

| 故障码 | 故障描述 | 可能原因 | 处理建议 |
|--------|---------|---------|---------|
| 0x01 | 电网一段过压 | 电网电压异常 | 检查电网质量 |
| 0x04 | 电网一段欠压 | 电网电压异常 | 检查电网质量 |
| 0x27 | 孤岛故障 | 电网断电 | 检查电网连接 |
| 0x3C | 母线短路 | 母线绝缘损坏 | 立即停机检查 |
| 0x7E | BMS通信异常 | CAN/RS485线路故障 | 检查线路/BMS电源 |

| 0xD4 | 电表通信故障 | RS485线路故障 | 检查电表接线 |

## 五、修复方案

### 5.1 远程修复流程

```
故障告警 → 自动诊断 → 远程修复尝试
                              ├── 参数重置（功率/电压/频率阈值）
                              ├── 软件复位（通信模块/控制单元）
                              ├── 固件升级（通过串口/MQTT）
                              └── 远程重启（安全条件下）
                              ↓
                        修复成功？ → 是 → 恢复运行
                              ↓
                              否 → 派单现场处理
```

### 5.2 现场修复流程

```
派单 → 工程师接单 → 携带备件 → 现场诊断
                              ├── 电气检查（电压/电流/绝缘）
                              ├── 通信检查（RS485/MQTT/CAN）
                              ├── 机械检查（接触器/继电器/风扇）
                              └── 环境检查（温度/湿度/防水）
                              ↓
                        更换故障部件
                              ↓
                        测试验证 → 恢复运行 → 工单闭环
```

### 5.3 常见故障修复指南

#### 5.3.1 通信故障修复

| 故障现象 | 检查步骤 | 修复措施 |
|---------|---------|---------|
| Modbus超时 | 1.检查RS485接线<br>2.测量A/B间电压<br>3.检查终端电阻<br>4.检查地址/波特率 | 1.重新接线<br>2.加终端电阻120Ω<br>3.修正参数 |
| MQTT断连 | 1.检查网络<br>2.检查MQTT Broker<br>3.检查设备ID<br>4.检查QoS设置 | 1.恢复网络<br>2.重启Broker<br>3.重新注册 |
| CAN通信异常 | 1.检查CAN_H/CAN_L<br>2.测量电压（2.5V/3.5V）<br>3.检查终端电阻<br>4.检查BMS电源 | 1.重新接线<br>2.加终端电阻120Ω<br>3.更换BMS |

#### 5.3.2 电气故障修复

| 故障现象 | 检查步骤 | 修复措施 |
|---------|---------|---------|
| 过压故障 | 1.测量输入电压<br>2.检查保护阈值<br>3.检查电网质量 | 1.调整变压器<br>2.修正阈值<br>3.加稳压器 |
| 过流故障 | 1.测量负载电流<br>2.检查短路<br>3.检查IGBT/MOSFET | 1.减少负载<br>2.排除短路<br>3.更换功率器件 |
| 绝缘故障 | 1.测量绝缘电阻<br>2.检查潮湿/灰尘<br>3.检查电缆破损 | 1.干燥处理<br>2.清洁<br>3.更换电缆 |

#### 5.3.3  thermal 故障修复

| 故障现象 | 检查步骤 | 修复措施 |
|---------|---------|---------|
| 机内过温 | 1.检查风扇<br>2.检查散热片<br>3.检查环境温度<br>4.检查通风口 | 1.更换风扇<br>2.清洁散热片<br>3.改善通风 |
| 接口过温 | 1.检查充电枪<br>2.检查接触电阻<br>3.检查电缆规格 | 1.清洁/更换枪头<br>2.紧固接线<br>3.更换电缆 |

### 6.2 数据库设计

#### 6.2.1 设备表
```sql
CREATE TABLE devices (
    id BIGINT PRIMARY KEY,
    device_code VARCHAR(50) UNIQUE,  -- 设备地址
    device_type VARCHAR(20),         -- inverter/charger/pcs
    station_id BIGINT,               -- 所属场站

    firmware_version VARCHAR(20),    -- 固件版本
    status VARCHAR(20),              -- online/offline/fault

);
```

#### 6.2.2 遥测数据表
```sql
CREATE TABLE telemetry (
    id BIGINT PRIMARY KEY,
    device_id BIGINT,
    timestamp TIMESTAMP,
    voltage_a DECIMAL(10,2),         -- A相电压
    voltage_b DECIMAL(10,2),         -- B相电压
    voltage_c DECIMAL(10,2),         -- C相电压
    current_a DECIMAL(10,2),         -- A相电流
    current_b DECIMAL(10,2),         -- B相电流
    current_c DECIMAL(10,2),         -- C相电流

    power_reactive DECIMAL(12,2),    -- 无功功率
    soc DECIMAL(5,2),                -- 电池SOC
    temperature DECIMAL(5,2),        -- 温度
    FOREIGN KEY (device_id) REFERENCES devices(id)
);
```

#### 6.2.3 故障记录表
```sql
CREATE TABLE fault_records (
    id BIGINT PRIMARY KEY,
    device_id BIGINT,
    fault_code VARCHAR(20),          -- 故障编码
    fault_level VARCHAR(10),         -- emergency/serious/general/info
    fault_source VARCHAR(50),        -- 故障源
    fault_time TIMESTAMP,            -- 故障时间
    fault_status VARCHAR(20),        -- active/cleared/acknowledged
    sequence_no BIGINT,              -- 故障流水号
```

## 八、总结

### 8.1 核心发现

1. **协议多样性**：光储充系统涉及Modbus-RTU、MQTT等多种协议，需统一采集层
2. **故障体系完善**：协议已定义完整的故障编码体系（4级200+故障码）
3. **数据维度丰富**：逆变器提供2000+寄存器，覆盖电气/ thermal /通信/电池全维度
4. **实时性要求高**：故障诊断需秒级响应，健康评估需分钟级更新

### 8.2 关键建议

1. **建立统一采集层**：屏蔽协议差异，统一数据模型
2. **构建故障知识库**：基于协议故障码建立诊断规则库
3. **实现预测性维护**：基于历史数据训练健康度模型
4. **远程修复优先**：80%故障可通过远程修复解决
5. **备件管理优化**：基于故障统计优化备件库存
