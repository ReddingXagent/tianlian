# 运维管理平台 SPEC

**版本**: v1.0  
**日期**: 2026-07-17  
**状态**: 详细设计

---

## 1. 定位与角色

### 一句话定位
面向运维工程师和站长的设备运维闭环平台，实现"发现问题→处理问题→解决问题→预防问题"的全链路设备生命周期管理。

### 面向用户角色

| 角色 | 描述 | 核心诉求 |
|------|------|----------|
| **运维主管** | 管理运维团队整体绩效 | 团队KPI、设备健康度总览、运维分析报表 |
| **运维工程师** | 一线故障处理与巡检 | 接收工单、现场处理、知识查询、移动端操作 |
| **站长** | 站点管理者 | 站点总览、报修、工单验收、运维评价 |
| **监控值班员** | 7×24监控告警 | 实时告警、设备遥测、应急处置 |

## 2. 功能闭环

### 2.1 监控告警（发现问题）

#### 功能清单

| 子功能 | 描述 | 核心元素 |
|--------|------|----------|
| **实时遥测** | 设备运行数据实时采集展示 | 功率(kW)、电压(V)、电流(A)、SOC(%)、温度(℃)、效率(%)、发电量(kWh) |
| **遥测历史** | 历史遥测数据查询与回放 | 时间范围选择、图表展示、数据导出、经典模式切换 |
| **告警列表** | 所有设备告警集中管理 | 设备名、告警类型、级别(紧急/警告/一般)、时间、状态(待处理/处理中/已解决)、处理工程师 |
| **告警详情** | 告警上下文信息 | 告警内容、设备快照(触发时的遥测值)、触发条件规则、处理建议(联动知识库) |
| **告警规则配置** | 阈值与规则定义 | 指标选择、阈值(警告/严重)、通知人、通知方式(短信/APP/邮件)、启用/停用 |
| **告警通知** | 多渠道告警推送 | APP推送、短信通知、邮件通知、通知规则可配置(时段/级别/静默期) |
| **故障诊断** | AI辅助故障根因分析 | 告警关联分析、设备历史故障画像、相似案例推荐、根因定位 |
| **智能诊断** | 基于规则的专家系统 | 故障代码匹配、诊断步骤引导、自动生成处置建议 |

#### 闭环流程

开始 → 设备遥测数据实时采集(秒级) → 告警规则引擎检测(阈值/模式匹配) → 触发告警 → 分级通知(APP推送/短信) → 工程师响应 → 标记处理中 → 定位故障(自诊断/AI辅助) → 处理解决 → 标记已解决 → 告警总结写入知识库 → **结束**

### 2.2 工单管理（处理问题）

#### 完整生命周期

| 子功能 | 描述 | 核心元素 |
|--------|------|----------|
| **工单列表** | 全平台工单展现 | 工单编号、设备名、站点、级别(紧急/警告/一般)、状态(待派单/待接单/进行中/待验收/已完成/已关闭)、工程师、创建时间 |
| **多维度筛选** | 灵活检索 | 按状态/级别/工程师/日期范围/站点/设备类型 |
| **创建工单** | 手动/告警自动创建 | 设备选择、级别、描述、派单方式(指派/抢单)、关联告警 |
| **工单详情** | 完整档案 | 基本信息、设备档案、工程师处理时间线、到场记录、过程记录、备件更换、附件(照片/视频) |
| **派单** | 指派工程师 | 智能推荐(就近/技能匹配/负载均衡)、手动选择、同时短信通知 |
| **接单/抢单** | 工程师认领 | 接单按钮、派单模式下自动指派 |
| **到场签到** | 打卡定位 | GPS定位签到、到场照片、到场时间记录 |
| **过程记录** | 处理过程留痕 | 文字描述、照片/视频上传、进度更新 |
| **申请支援** | 寻求高级工程师协助 | 支援请求、被指派工程师、远程协助 |
| **申请备件** | 物料需求 | 备件名称、型号、数量、原因、审批流 |
| **转单** | 转给其他工程师 | 目标工程师选择、转单原因、原工程师记录留痕 |
| **催单** | 催促处理 | 催单按钮、短信通知站长/主管 |
| **完成提交** | 处理报告 | 故障原因、处理方案、更换配件明细、现场照片、站长确认签名 |
| **验收评价** | 站长方验收+评价 | 星级评价(响应速度/维修质量/服务态度)、文字评价 |
| **工单统计** | 多维度分析 | 按状态/工程师/级别/站点/设备类型统计、趋势图 |
| **我的工单** | 个人工作台 | 待接单数、进行中数、今日已完成数 |

#### 闭环流程

**完整工单生命周期**  
开始 → 工单创建(告警自动触发/手动创建/站长APP报修) → 派单(自动/手动) → 工程师接单 → 导航到站 → 到场签到(GPS+照片) → 现场勘测诊断(含V2G设备专项检测) → 记录处理过程(文字+照片+视频) → 如需备件→申请备件审批→领料→更换 → 完成维修 → 提交流程 → 站长验收 → 评价 → 工单关闭 → 故障案例沉淀知识库 → **结束**

**告警→工单自动流转**  
开始 → 设备触发严重告警 → 告警规则判定需创建工单 → 自动生成紧急工单 → 智能派单(按技能+就近+负载) → 通知工程师 → 工程师响应处理 → 处理完成关闭告警+工单 → **结束**

### 2.3 站点管理

| 子功能 | 描述 | 核心元素 |
|--------|------|----------|
| **站点列表** | 所有站点展示 | 站点名称、地址、容量(MW)、设备数、健康度、状态、运维团队、操作 |
| **站点CRUD** | 站点增删改查 | 名称/地址/经纬度/容量/建成日期/站长/运维团队/描述/图片 |
| **站点详情** | 完整信息查看 | 基本信息、设备列表(光伏/储能/直流充电/交流充电/V2G)、工单记录、健康评分 |
| **站点健康评估** | 站点评分模型 | 基于设备健康度加权计算、绿/黄/红状态标识 |
| **站点分配** | 分配给运维团队 | 运维团队下拉选择、确认 |

#### 闭环流程

开始 → 新建站点(录入基本信息) → 分配站长+运维团队 → 设备接入关联 → 日常运维监控 → 健康评估(定期) → 健康分下降触发运维动作 → 站点维护 → 健康分更新 → **持续循环**

---

### 2.4 设备管理

| 子功能 | 描述 | 核心元素 |
|--------|------|----------|
| **设备列表** | 全量设备展示 | 设备名称、类型(光伏/储能/直流充电/交流充电/V2G)、型号、所属站点、利用率(%)、健康度、状态、运行时间 |
| **设备筛选** | 多维度过滤 | 类型/站点/状态/效率阈值 |
| **设备CRUD** | 增删改查 | 名称/类型/型号/SN/站点/安装日期/品牌/功率/V2G能力/供应商 |
| **设备详情** | 完整设备档案 | 基本信息、运行参数、效率曲线(利用率/充电效率/发电效率)、V2G运行状态、维护记录、故障历史、工单记录 |
| **健康度评估** | 设备健康模型 | 评分(0-100)、状态(健康/亚健康/故障)、上次评估时间、影响因素分解 |
| **维护计划** | 定期维护提醒 | 维护周期(天)、下次维护日期、维护记录列表、到期提醒 |
| **设备控制** | 远程操控 | 充电桩:启动/停止/功率调节；V2G:充电/放电/待机模式切换、充放电功率上限、V2G调度策略配置 |
| **巡检记录** | 周期性巡检 | 巡检计划、巡检项、巡检结果、异常标记、巡检报告 |

#### 闭环流程

开始 → 设备安装接入 → 建立设备档案 → 日常遥测监控 → 健康度实时评估 → 健康分低于阈值 → 触发维护建议/创建工单 → 工程师检修 → 更新设备健康分 → 设备维护记录 → 定期巡检 → **持续循环**

### 2.5 预防性维护（预防问题）

| 子功能 | 描述 | 核心元素 |
|--------|------|----------|
| **预测性维护** | AI预测设备故障 | 基于历史数据+机器学习、故障预测评分、建议维护窗口、自动生成工单 |
| **巡检运维** | 周期性巡检计划 | 巡检模板、周期配置、任务生成、执行记录、报告导出 |
| **设备效率分析** | 效率趋势监控 | 利用率统计(<30%闲置预警、>90%过载标记)、充电效率趋势、发电效率(PR值)分析 |
| **V2G设备专项** | 双向设备特殊运维 | 充放电效率测试、转换效率计算、电池健康度评估、电网调度响应监测 |

### 2.6 知识库与自愈

| 子功能 | 描述 | 核心元素 |
|--------|------|----------|
| **知识分类** | 多维知识分类 | 故障案例/维修手册/培训资料/设备文档、分类树管理 |
| **知识文章** | 富文本知识内容 | 标题/分类/内容(支持图片/视频/附件)、作者、阅读量 |
| **知识检索** | 全文搜索 | 标题/内容关键词搜索、标签过滤 |
| **Runbook** | 自动化运维脚本 | 故障处理步骤编排、自动化执行、审批流程 |
| **自愈引擎** | 自动恢复机制 | 检测→诊断→执行恢复脚本→验证恢复→记录，支持常见故障自动恢复 |
| **健康检查** | 系统健康巡检 | 自动检测项、结果报表、异常修复建议 |

### 2.8 站长APP（移动端）

| 子功能 | 描述 | 核心元素 |
|--------|------|----------|
| **首页(站点总览)** | 我的站点概览 | 站点选择器、设备总数/正常/告警/离线、待处理告警、进行中工单、快捷操作(报修/巡检) |

| **消息** | 站内消息通知 | 告警通知、工单通知、巡检提醒 |

#### 站长APP闭环

开始 → 站长登录APP → 首页查看站点总览/告警/工单 → 发现异常 → 手动报修 → 工单自动创建 → 等待工程师处理 → 跟踪工单进度 → 工程师完成 → 站长验收 → 评分评价 → **结束**

### 2.9 工程师APP（移动端）

| 子功能 | 描述 | 核心元素 |
|--------|------|----------|
| **工作台首页** | 今日工作概览 | 待接单数、进行中数、已完成数、紧急工单提醒 |
| **待接单** | 待处理工单 | 紧急程度、设备名、站点、派单时间、接单/转单按钮 |
| **进行中** | 处理中工单 | 到场状态、记录进度、申请支援/备件、完成按钮 |
| **工单执行** | 完整处理流程 | 导航到站、到场签到(拍照+GPS)、故障诊断、过程记录(文字/照片/视频)、备件申请、完成提交 |
| **V2G专项** | 双向设备检测 | V2G设备诊断(充放电效率测试)、效率检测工具、调度响应确认 |
| **知识库** | 离线知识查阅 | 故障案例、维修手册、培训资料、支持离线缓存 |
| **我的** | 个人信息 | 个人资料、工作统计(本月工单/评分/响应时间)、消息通知 |

#### 工程师APP闭环

开始 → 收到工单通知(APP推送) → 打开APP查看工单详情 → 接单 → 导航到现场 → 到场签到(GPS+照片) → 故障诊断(辅助知识库+诊断工具) → 记录处理过程 → 如需备件→申请备件 → 更换/维修完成 → 提交完成报告(含照片) → 等待站长验收 → **结束**

### 2.10 智能运维分析

| 子功能 | 描述 | 核心元素 |
|--------|------|----------|
| **运维仪表板** | 综合运维KPI | 工单量趋势、响应时效排行、站点健康分布、设备状态分布 |
| **分析仪表板** | AI运维洞察 | 异常模式识别、设备寿命预测、维修热点地图、效率异常预警 |

| **能耗分析** | 站点能效评估 | 能效比、损耗分析、优化建议 |
| **数字孪生** | 3D站点可视化 | 设备三维展示、实时数据叠加、异常高亮、空间定位 |

## 5. 与其他板块的边界

| 交互方 | 本板块提供 | 本板块依赖 |
|--------|-----------|-----------|
| **运营管理平台** | 设备状态数据(用于利用率->营收关联分析) | 运营订单数据(用于分析效率与营收关联) |
| **车队管理平台** | — | — |
| **平台管理** | 运维团队数据 | 用户体系(Users)、权限控制(RBAC)、消息中心(MessageCenter) |

### 不归属于本板块的功能
- 费用定价/订单支付 → 归运营管理平台
- 用户类型管理(5种)/优惠券/积分 → 归运营管理平台
- 车辆/车队/司机管理 → 归车队管理平台
- 物联网协议/设备库/网关管理 → 归平台管理
- 系统级用户/角色/权限管理 → 归平台管理
- 互联互通/市政监管对接 → 归平台管理
