# 光储充能量策略 SPEC（能量管理与充放电调度）

> 状态：**草案 v0.1 — 待丁哥确认规则**

> 范围：场站级能量管理策略（EMS 策略层），不含设备协议采集（已有）和充电订单计价（pricing_v2 已有）
> 关联：SPEC.md §设备控制/效率分析、docs/光储充设备运维与故障诊断方案.md、backend/app/models/charging_schedule.py、pricing_v2.py

## 1. 背景与目标

现状：后端已有充电调度引擎（峰/平/谷时段 + 谷时填充 + V2G 优化规则）和对客分时电价模型（pricing_v2），
但缺少**光储充一体化的能量策略层**：光伏的电往哪走、储能何时充放、按地区/场景如何差异化，均无规则定义。

目标：
1. 定义场站能量流优先级（光伏就地消纳 → 余电储能 → 电网兜底 → 可选上网）
2. 定义储能充放电策略（峰谷套利 / 动态增容 / 需量管理 / 新能源消纳），以**价格信号驱动**
3. 价格层与规则层解耦，支持电价变动（版本化）与未来电力现货市场（15 分钟 × 96 节点）
4. 支持地区差异（省级分时电价模板库）与场景差异（4 类场站策略预设）

## 2. 核心设计原则

### 2.1 规则与价格解耦
- 调度规则只认**价格信号**，不写死时段：`购电价 < 充电阈值 → 充电`，`购电价 > 放电阈值且价差 ≥ 最小套利空间 → 放电`
- 时段（峰/平/谷/尖峰）只是价格的载体；电价政策调整 = 更新价格数据层，规则不动

### 2.2 价格曲线抽象（现货兼容）
- 价格统一建模为**时间→购电单价的曲线**：
  - 现行分时电价 = 阶梯状曲线（按峰平谷时段的分段常数）
  - 电改现货 = **15 分钟 × 96 节点/天**的连续曲线（暂未实施，预留兼容）
- 同一接口、不同分辨率；调度引擎决策周期固定 **15 分钟**，天然对齐 96 节点
- 现货阶段支持**日前价（预测曲线）+ 实时价**：日前按 96 点曲线排全天充放电计划，实时滚动修正（每 15 分钟重算下一窗口）

### 2.3 电价版本化
- 分时电价表带 `effective_from / effective_until` + 版本号；政策调整新增一版，不改写历史
- 历史结算/订单按**当时生效版本**计算，不追溯
- 支持**季节性电价**：同一地区按月份区间配多套时段表（如夏季尖峰 7-8 月、冬季高峰 12-1 月）
- 价格来源可插拔：① 运营手动录入（电网公司文件）② 未来可接省电力现货 API 自动同步

## 3. 能量流：可调优先级链路（光伏消纳）

⚠️ **能量流不是写死的固定链路，而是可编排的优先级链**——每个场站可调顺序、开关、限参。

默认优先级（可调整）：

```
光伏出力
  ├─ [默认P1] 就地直供：供给本站充电桩负载（自发自用，省购电）
  ├─ [默认P2] 余电储能：光伏 > 本站负载 → 余量给储能充电
  ├─ [默认P3] 余电上网（默认关闭）：储能满 + 光伏仍有余 → 并网卖电
  │     └─ 开关按地区政策配置；关闭时执行弃光保护（降光伏出力）
  └─ 光伏不足时：
        ├─ [默认P4] 储能放电补充负载
        └─ [默认P5] 电网兜底购电
```

可调维度（场站级配置）：
- **顺序可调**：优先级序号可重排。例：峰时某站可设「储能放电(P1) > 光伏直供(P2)」优先消耗谷电充的储能；余电充裕站可设「余电储能」高于「就地直供」先把电池喂饱
- **环节开关**：每个环节独立 on/off（上网环节默认 off；离网站可关「电网兜底」改纯保供）
- **环节限参**：每环节可设功率上限/分配比例（如「光伏直供最多占出力的 70%，其余强制入储」）

硬约束（不可被配置突破）：
- 变压器容量上限约束总出力（光伏+储能+电网 ≤ 变压器容量 + 储能增容额度）
- 防逆流保护：不允许上网的地区，上网环节强制关闭且并网点功率方向监控（反向功率 → 降光伏/储能充电吸收）
- SOC 底线与 BMS 功率约束（见 §4.3）

## 4. 储能充放电策略（多策略并行 + 仲裁）

⚠️ **各策略不是互斥单选，而是并行运行**：套利、增容、需量、保供可同时开启，各自独立产出「功率建议」，冲突由仲裁层合成最终指令。

架构：

```
策略1 峰谷套利   ──→ 建议: 放电 +50kW ┐
策略2 动态增容   ──→ 建议: 放电 +30kW ├→ 仲裁器（优先级+权重+约束）→ 最终功率指令
策略3 需量管理   ──→ 建议: 放电 +20kW │    ├ 优先级：保供 > 安全 > 需量 > 增容 > 套利（默认，可调）
策略4 保供预留   ──→ 建议: 充电 保持  ┘    ├ 同向建议取大/叠加（可配叠加上限）
                                         └ 反向建议按优先级裁决
硬约束校验：SOC底线 / BMS功率 / 变压器容量 / 循环次数 → 裁剪后下发
```

仲裁规则：
- **反向冲突**（一策略要充、另一要放）：按策略优先级裁决，默认 `保供 > 安全 > 需量管理 > 动态增容 > 峰谷套利 > 新能源消纳`，优先级场站可调
- **同向叠加**（多策略都要放电）：默认取最大功率建议（不叠加，避免过放），可配「允许叠加+叠加上限」
- **权重模式（可选高级）**：各策略带权重，仲裁按权重加权合成功率，适合精细调优
- 每次仲裁产出**决策日志**（哪个策略胜出、为什么），供前端展示和审计

策略开关与参数均场站级可配：每个策略独立 on/off + 阈值参数 + 优先级序号。

### 4.1 充电时机（双来源）
| 触发条件 | 来源 | 说明 |
|---|---|---|
| 购电价 < 充电阈值（谷段） | 电网 | 谷电低价充电，峰时放出套利 |
| 光伏余电（P2 触发） | 光伏 | 免费消纳，优先于电网充电 |
| 现货模式：日前曲线低价节点 | 电网/光伏 | 按 96 点曲线优化充电分布 |

### 4.2 放电时机
| 策略 | 触发条件 | 目标 |
|---|---|---|
| **峰谷套利** | 购电价 > 放电阈值 且 峰谷价差 ≥ 最小套利空间 | 低买高卖赚价差 |
| **动态增容** | 充电负载预测 > 变压器容量 | 储能放电补差，省变压器扩容费 |
| **需量管理** | 本月最大需量接近申报值（两部制站点） | 削峰压低最大需量，省基本电费 |
| **保供优先**（离网/弱网场景） | 电网故障/限电 | 储能转保供模式，不参与套利 |

### 4.3 安全底线（不可突破）
- **SOC 下限预留**：默认 10%（可配），低于下限停止一切套利性放电
- **应急备用电量**：可配固定保留区间（如 10%-20%），仅电网故障时动用
- 电池保护：充放电功率受 BMS 实时约束（温度/SOH 降额），高寒高海拔地区按温度曲线降额（对应乌科梁子/采乃试点）
- 每日完整充放次数上限（循环寿命保护，可配）

## 5. 地区差异：省级分时电价模板库

模型：`省份 → [季节区间 → 时段表(尖/峰/平/谷 + 浮动比例)] + 上网政策开关 + 两部制标记`

第一批 4 个典型省份（规则为示意值，上线前按最新电网文件校准）：

| 省份 | 典型特征 | 时段特点 | 策略倾向 |
|---|---|---|---|
| **四川** | 水电富余，谷电便宜 | 谷段长、价差中等、丰枯季节电价 | 谷时多充、光伏自用为主 |
| **浙江** | 高价差、双高峰 | 夏冬季尖峰、两峰两谷、价差大 | 套利优先 + 需量管理 |
| **广东** | 沿海大负荷 | 尖峰电价高、夏季长峰段 | 套利 + 动态增容（快充站扩容贵） |
| **甘肃** | 光伏富集、西北 | 谷段深（午间光伏大发谷电）、现货试点省 | 现货 96 节点先行适配、午间充电 |

场站创建时选省份 → 自动套用模板；运营可基于模板微调（覆盖层）。
模板库版本化管理，电网政策更新 → 新增模板版本 + 生效日期。

## 6. 场景差异：4 类场站策略预设

| 场景 | 负载特征 | 主策略 | 次策略 |
|---|---|---|---|
| **车队站** | 充电需求可预测（固定车队排班） | 谷充峰放套利 | 光伏自用 + 按排班预留 SOC |
| **公共快充站** | 负载随机、峰值高 | 动态增容 + 需量管理 | 峰谷套利 |
| **离网/弱网站**（试点类） | 电网弱/无电网 | 保供优先（SOC 高水位保持） | 光伏最大化自用，套利让位可靠性 |
| **V2G 参与站** | 车队电池可调度 | 储能+V2G 联合峰谷调节 | 车辆放电收益分成 |

每个场站绑定一个场景预设 → 决定策略权重与 SOC 目标曲线；可在预设基础上调参。

## 7. 调度引擎工作流

```
每 15 分钟（对齐 96 节点）:
  1. 读取：当前价格曲线版本 + 光伏出力预测 + 充电负载预测 + 储能 SOC/BMS 状态 + 场景预设
  2. 优化：在约束（变压器容量/SOC 底线/循环次数/防逆流）下，求下一窗口各设备功率设定
       - 现行阶段：规则引擎（阈值比较 + 优先级）
       - 现货阶段：日前 96 点全局优化 + 实时滚动修正
  3. 下发：光伏限功率指令 / 储能充放电功率指令 / 充电桩功率分配
  4. 记录：能量流水（光伏发/充/放/购/上网，15min 粒度）→ 供效率分析与结算
```

与现有 charging_schedule 的关系：现有引擎管"车怎么排队充电"（需求侧），新策略层管"电从哪来、储能怎么动"（供给侧），两层协同——供给侧算出可用功率预算，需求侧在预算内排车。

## 8. 数据模型草案（后端）

| 表 | 说明 |
|---|---|
| `energy_price_template` | 省级电价模板（省份/版本/生效区间/季节/上网开关/两部制标记） |
| `energy_price_period` | 模板下的时段明细（尖/峰/平/谷 + 起止时刻 + 电价或浮动比例） |
| `energy_price_spot`（预留） | 现货 96 节点价格（站点/日期/节点序号/日前价/实时价） |
| `station_energy_strategy` | 场站策略（绑定模板版本 + 场景预设 + 阈值参数 + SOC 底线/备电区间） |
| `energy_dispatch_plan` | 调度计划（15min 窗口 × 设备功率设定 + 依据价格版本） |
| `energy_flow_log` | 能量流水（15min 粒度：光伏发电/直供/储充/储放/购电/上网） |
